# Lista Sequencial e Encadeada

Projeto desenvolvido para a disciplina de Estrutura de Dados I — 2026.1, P3

## Sobre o projeto

O sistema gerencia uma sala de até 60 alunos. Cada aluno, identificado pelo RGM, possui uma lista de disciplinas com suas respectivas notas.

A estrutura utiliza:
- **Lista sequencial estática** para armazenar os alunos (máximo 60), com inserção ordenada por RGM
- **Lista encadeada dinâmica** para armazenar as disciplinas de cada aluno

## Funcionalidades

- Cadastrar aluno em ordem crescente de RGM, com suas disciplinas
- Listar todos os alunos e suas disciplinas
- Buscar aluno pelo RGM
- Remover aluno pelo RGM e exibir a lista atualizada
